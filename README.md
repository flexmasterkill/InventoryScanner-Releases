# Inventory Scanner Releases

This repository contains signed Android APK releases and machine-readable update metadata for Inventory Scanner. It does not contain application source code, signing keys, inventory data, or manuals.

Only install APKs whose release checksum matches the published metadata. The expected signing certificate SHA-256 is:

`CDBB5CE479E6795E3F33447BD8BB6B123DBC978E021662CC42F1F4D17A8FE4C1`

Android updates preserve app data when the package name and signing certificate match the installed app.
